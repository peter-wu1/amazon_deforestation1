# Amazon Deforestation & Climate Analysis 🌳🔥

This repository contains a comprehensive data analysis of deforestation and fires in the Brazilian Amazon. It explores historical data and investigates potential correlations with regional metrics and global climate patterns such as El Niño and La Niña.

## 📊 Project Overview
The Amazon rainforest plays a crucial role in global climate regulation. This project uses Python and Jupyter Notebooks to analyze decades of environmental data to uncover trends in deforestation, fire outbreaks, and the impact of climate anomalies on the Brazilian Amazon.

## 📁 Repository Structure
* **`amazon_deforestation.ipynb`**: The main Jupyter Notebook containing the data exploration, preprocessing, analysis, and visualizations.
* **`brazil.json`**: GeoJSON or topographical data used for mapping and geospatial analysis of Brazil.
* **`deforestation_2004_2019.csv`**: Historical data on deforestation rates in the Amazon from 2004 to 2019.
* **`inpe_brazilian_amazon_fires_1999_2019.csv`**: Official dataset from INPE (National Institute for Space Research) detailing fire occurrences in the Brazilian Amazon between 1999 and 2019.
* **`el_nino_la_nina_1999_2019.csv`**: Climatological data tracking El Niño and La Niña events to correlate with fire and deforestation spikes.
* **`brazil_states_2019.csv`**: State-level data for Brazil (likely population, area, or economic metrics) for the year 2019.
* **`brazil_ir_gs_tb_2004_2020.csv`**: Supplementary macroeconomic or environmental metrics spanning 2004 to 2020.
